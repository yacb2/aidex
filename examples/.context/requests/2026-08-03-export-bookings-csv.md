# Export bookings as CSV

## Description

Facilities wants a monthly CSV of bookings per building for utilisation reports.

## Context

Today they copy the calendar into a spreadsheet by hand at month end.

## Acceptance Criteria

- One row per booking: room, building, start, end, booked by.
- Filterable by month; downloadable from the bookings list.

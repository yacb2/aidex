# v1.0.0 — aidex ships as a plugin

aidex now installs as a Claude Code plugin instead of a `git clone` + `./install.sh`
checkout. This is the first GitHub Release since v0.30.0.

## Install

```
/plugin marketplace add yacb2/aidex
/plugin install aidex
```

Restart Claude Code afterward.

## What changed for you

- **Install is a plugin, not a clone.** Nothing is copied into `~/.claude/` and nothing
  is symlinked. `.claude-plugin/plugin.json` declares the plugin and
  `.claude-plugin/marketplace.json` makes this repo its own marketplace.
- **Skills are invoked as `/aidex:<name>`.** All 19 skills ship from `skills/`: aidex,
  artifact, audit, backlog, bugfix, comm, conventions, coverage, decision, loop, plan,
  plan-exec, reference, request, research, review, skill, workflow, worktree.
- **`aidex-dash` is now `aidex-artifact`.** Same job, no separate slash command needed —
  describe the artifact you want (report, dashboard, HTML page) and it triggers by
  description.
- **Hooks are auto-wired.** `hooks/hooks.json` wires four hooks automatically on
  install: `memory-audit-nudge.sh` (SessionStart), `memory-save-gate.sh` (PreToolUse on
  Write/Edit/MultiEdit), `artifact-open-once.sh` (PreToolUse on Bash), and
  `context-depth-nudge.sh` (UserPromptSubmit). You no longer edit `~/.claude/settings.json`
  by hand.
- **The always-on rules are gone.** A plugin cannot ship always-on rules, so each
  retired `rules/*.md` file's canon now lives in a skill reference, cited by the skills
  that need it:
  - `aidex-conventions.md` -> `skills/conventions/references/00-global.md`
  - `autonomy.md` -> `skills/conventions/references/autonomy-conventions.md`
  - `verification-before-claims.md` -> `skills/conventions/references/human-verification-conventions.md`
  - `database-protection.md` -> `skills/conventions/references/database-protection.md`
  - `memory-hygiene.md` -> `skills/aidex/references/memory-hygiene.md` (what the memory gate and sweep implement)
  - `artifacts-local-first.md` -> `skills/artifact/references/02-local-first-artifacts.md` (the artifact skill's description does the routing)
  - `e2e-testing.md` -> the coverage skill's testing-profile template
  - `root-cause-first.md` and `harness-lessons.md` were the author's personal doctrine and
    are not part of the product; keep your own copy under `~/.claude/rules/` if you want them.

## Migrating from a pre-1.0 install

1. In your old checkout, run `./install.sh --uninstall`.
2. Open `~/.claude/settings.json` and remove the 4 hook lines pointing at
   `~/.claude/hooks/*.sh`.
3. Remove any `skillOverrides` entry for `aidex-dash` (it no longer exists under that
   name).
4. Install the plugin as shown above.

Rollback: `git checkout v0.55.0 && ./install.sh`.

## Known gaps

- `--doctor` is not yet available. It returns later as a `/aidex:aidex` sub-action

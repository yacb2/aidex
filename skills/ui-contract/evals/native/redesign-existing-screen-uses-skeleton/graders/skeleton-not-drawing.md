`propuesta.md` must (a) name the current home page (`HomePage.vue`) as the reference
screen, (b) propose a level for the owner to confirm instead of deciding it silently, and
(c) plan to show the redesign as a skeleton built from the project's real components
(`PageShell`, `StatCard`) on fixture data, with gallery captures.

Fails if: it plans or briefs any drawn artifact (an SVG, a wireframe, a low-fi sketch, a
mockup, a figure agent); it presents a drawn round as non-binding or optional; it shows
only the current screen as the proposal.

Does not count against it: stating that nothing will be drawn.
